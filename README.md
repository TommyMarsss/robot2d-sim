# robot2d-sim

2D 移动机器人仿真与自主导航系统。

- 运行环境：Python 3.11（仅标准库，不依赖 numpy 等第三方包）

## EKF 定位模块

基于扩展卡尔曼滤波的平面机器人定位：融合带噪声的里程计增量与已知路标的
距离-方位观测，在线估计机器人位姿及其不确定度，并对定位发散 / 机器人被
绑架（kidnap）进行检测与报告。

### 快速开始

```bash
# 1. 生成一份示例传感器日志（含真值、噪声、乱序时间戳与一次绑架事件）
python -m robot2d.simlog -o sample_log.jsonl

# 2. 运行滤波并生成单文件 HTML 交互回放报告
python -m robot2d.run sample_log.jsonl -o ekf_report.html

# 3. 用浏览器打开 ekf_report.html：拖动时间轴 / 逐步回放 /
#    切换估计轨迹、真值轨迹、误差与 NIS 曲线；发散与绑架时刻有明确标记
```

### 状态与噪声模型

**状态向量** `x = [x, y, θ]ᵀ`：平面位置（m）与航向角（rad，归一化到
`(-π, π]`，所有角度运算均做环绕处理，跨越 ±180° 不产生跳变）。

**运动模型**（里程计增量，中点积分）：

```
输入 u = (d, dθ)：机器人系下前进距离与转角
x' = x + d·cos(θ + dθ/2)
y' = y + d·sin(θ + dθ/2)
θ' = wrap(θ + dθ)
```

里程计噪声随运动量增长（模拟打滑）：

```
σ_d  = α_d·|d| + α_dθ·|dθ| + floor_d      （默认 0.08 / 0.03 / 0.005）
σ_dθ = α_θ·|dθ| + floor_θ                 （默认 0.15 / 0.002）
```

**观测模型**（已知路标 `id → (lx, ly)` 的距离-方位）：

```
z = (r, φ)，h(x) = (√(dx²+dy²), wrap(atan2(dy,dx) − θ))
R = diag(σ_r², σ_φ²)，默认 σ_r = 0.15 m，σ_φ = 0.05 rad
```

**协方差数值稳定性**：更新采用 Joseph 形式；每步对称化 `P`；对角线设下限
并在必要时对角加载（jitter），保证 `P` 始终对称半正定，长时间运行不退化
（有对应测试覆盖 5000 步纯航位推算与 3000 步混合运行）。

**发散 / 绑架检测**：每次观测更新计算 NIS（归一化新息平方
`yᵀS⁻¹y`，2 自由度卡方 99% 门限 9.21）：

- 单次 NIS > 100 → 判定**绑架**，主动放大协方差使滤波器能重新收敛；
- 滑动窗口（10 次观测）内 ≥60% 超门限 → 判定**发散**；
- 之后连续 5 次观测新息恢复正常 → 报告**恢复**。

所有事件带时间戳记录在 `EKFLocalizer.events`，并在 HTML 报告的地图与
曲线上标出。

### 日志文件格式

JSON Lines，每行一个事件。**时间戳允许乱序与重复**：解析后按
`(t, 类型优先级, 载荷)` 全序排序（与输入顺序无关，结果可复现），
完全重复的事件自动去重。

```json
{"type": "config", "landmarks": {"0": [5.0, 0.0], "1": [5.0, 5.0]}}
{"type": "init", "t": 0.0, "x": 0.0, "y": 0.0, "theta": 0.0}
{"type": "odom", "t": 0.1, "d": 0.05, "dtheta": 0.002}
{"type": "obs", "t": 0.1, "landmark": "0", "range": 4.95, "bearing": -0.11}
{"type": "truth", "t": 0.1, "x": 0.05, "y": 0.0, "theta": 0.0}
```

- `config`：路标表（也可用 `python -m robot2d.run --landmarks '{...}'` 传入）；
- `init`：初始位姿，缺省为原点；
- `odom`：里程计增量 `d`（m）、`dtheta`（rad）；
- `obs`：路标观测，`range`（m）、`bearing`（rad，机器人系相对方位）；
- `truth`：可选真值，仅用于报告中的误差曲线，不影响滤波。

### 代码结构

| 文件 | 职责 |
| --- | --- |
| `robot2d/linalg.py` | 纯 Python 矩阵运算、PSD 修复、协方差椭圆 |
| `robot2d/ekf.py` | EKF 核心（预测/更新/环绕/发散检测），可独立测试 |
| `robot2d/logio.py` | 日志解析、乱序重排、去重、滤波驱动 |
| `robot2d/simlog.py` | 示例日志仿真生成器 |
| `robot2d/report.py` | 单文件 HTML 报告生成（数据与 JS 全内嵌） |
| `robot2d/run.py` | 命令行入口 |
| `tests/test_ekf.py` | 单元测试：`python -m unittest discover -s tests -v` |

### 已知限制

- **数据关联是已知的**：观测自带路标 id，不做关联匹配；错误关联的观测
  只能靠 NIS 门限部分缓解，可能诱发误判发散。
- **EKF 线性化误差**：大角度、大不确定度下一阶线性化不准，估计可能有偏
  （此时更合适的方案是 UKF 或粒子滤波）。
- **发散检测基于新息统计**：门限与窗口参数（`EKFConfig`）需按传感器
  特性调节；观测过于稀疏时检测会延迟甚至失效（没有观测就没有新息）。
- **绑架恢复策略简单**：仅靠放大协方差重新收敛；若绑架后观测仍然稀疏
  或路标不可见，无法保证恢复。
- **噪声模型为高斯白噪声**：未建模里程计系统误差（轮径偏差等）与
  观测中的多径/离群值；非高斯离群观测会显著拉偏估计。
- **平面假设**：仅适用于平整地面上的 2D 运动，无 IMU 融合与打滑检测。
