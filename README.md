# EKF 2D 机器人定位与回放

纯 Python 3.11 标准库（**无 numpy / 无任何第三方依赖**，矩阵运算手写）实现的
平面位姿 `(x, y, θ)` 扩展卡尔曼滤波定位模块。输入固定的传感器日志
（带噪里程计增量 + 已知路标的距离-方位观测，时间戳允许乱序/重复），
输出位姿估计、协方差、健康判定，并生成**单一静态 HTML 文件**做交互式回放。

## 快速开始

```bash
# 1) 生成三份内置场景日志（健康 / 绑架 / 发散，含真值）与一份乱序日志
python3 tools/generate_logs.py            # 写入 data/*.jsonl

# 2) 运行滤波，终端打印健康摘要并生成单文件 HTML 报告
python3 run_ekf.py data/kidnapped.jsonl   # -> report_kidnapped.html
python3 run_ekf.py data/diverged.jsonl
python3 run_ekf.py data/healthy.jsonl --no-report   # 只要算法结果

# 3) 浏览器直接打开（无需起服务、无网络请求）
open report_kidnapped.html

# 4) 跑测试（34 个，核心算法测试不依赖报告生成）
python3 -m unittest discover -s tests -v
```

## 状态与噪声模型

**状态**：`x = [x, y, θ]ᵀ`，单位米、米、弧度，θ 规范在 `(-π, π]`。

**运动模型**（输入为本体系里程计增量 `u = [Δs, Δθ]`，一阶航位推算）：

```
x′ = x + Δs·cosθ
y′ = y + Δs·sinθ
θ′ = wrap(θ + Δθ)
```

预测：`P = F P Fᵀ + Q`，其中 `F = ∂f/∂x`（θ 行含 `-Δs·sinθ / Δs·cosθ`）。
过程噪声采用经典里程计四系数模型，控制噪声 `M = diag(σ_s², σ_θ²)` 经
控制雅可比 `V`（Δs 沿当前航向投影到世界系）映射为 `Q = V M Vᵀ`：

```
σ_s² = α1·Δs² + α2·Δθ²
σ_θ² = α3·Δs² + α4·Δθ²
```

**观测模型**（已知路标 `(l_x, l_y)`，距离-方位）：

```
r   =  sqrt((l_x-x)² + (l_y-y)²)
φ   =  wrap(atan2(l_y-y, l_x-x) − θ)
```

更新：`ν = z − h(x)`（**方位分量按最短角差计算，自动处理 ±180° 环绕**），
`S = H P Hᵀ + R`，`K = P Hᵀ S⁻¹`，`x ← x + Kν`；
`R = diag(σ_r², σ_φ²)` 由日志 `meta.meas_var` 给出。

## 协方差数值稳定性（对应需求一）

1. **Joseph 形式**更新协方差 `P = (I−KH)P(I−KH)ᵀ + KRKᵀ`，结构上保持半正定；
2. 每次预测/更新后**对称化** `P ← (P+Pᵀ)/2`；
3. Jacobi 特征分解后把特征值钳制到正区间再重建，并对各分量补方差下限
   （加 PSD 秩一项），杜绝长时间运行退化为奇异/非正定；
4. 里程计即使增量为零也保留噪声底，避免"零增量零协方差"。

测试 `tests/test_ekf_core.py` 覆盖 20000 步纯航位推算、5000 步带观测、
2000 次重复观测三种压力场景，逐步检查特征值恒正、有限、对称。

## 角度环绕

所有航向/方位进状态前 `wrap` 到 `(-π, π]`；观测残差用 `wrap(bearing − φ̂)`，
因此 179° 与 −179° 的差为 −2° 而非 −358°，跨越 ±180° 不产生跳变误差。
测试覆盖分支割点、整圆周旋转跟踪、临界方位残差。

## 发散 / 绑架检测（对应需求二）

每次观测更新计算**归一化新息平方** `NIS = νᵀ S⁻¹ ν`（2 维观测，参照 χ²(2)：
95%=5.99，99%=9.21，1−10⁻⁶≈27.6）：

- **单点鲁棒门控**：NIS > 9.21 时按比例膨胀该观测的 R，抑制单点野值；
  该瞬时态（warn）只体现在回放徽章，**不计入事件报告**（健康数据统计上
  本就有约 1% 观测超 99% 门限）。
- **绑架**：连续观测中（距上次观测 ≤5s）连续 2 次 NIS > 27.6，判
  `KIDNAPPED` —— 机器人被瞬间搬运。触发后重置位置协方差并用当前观测
  立即重定位。
- **发散**：连续 4 拍新息异常 / NIS 持续偏大（滑动窗口均值超 95% 门限），
  或观测黑窗重捕获后出现极端新息（与绑架区分：黑窗后的大残差更可能是
  航位推算漂移），或长时间无观测导致位置标准差膨胀超 5m，判 `DIVERGED`。
  触发时自适应膨胀协方差一拍。
- **粘滞 + 恢复**：异常状态不会被单次正常观测取消；连续 5 拍 NIS 回到
  90% 门限（4.61）以内才记录"恢复"并回到健康。判定时刻、恢复时刻在
  HTML 地图与三条曲线上均有醒目标注，终端也打印中文摘要。

## 日志文件格式（JSON Lines，UTF-8）

每行一个 JSON 对象：

```json
{"type":"meta","landmarks":{"lm1":[2.0,2.0],"lm2":[-2.5,1.5]},
 "initial_state":[0,0,0],"initial_cov_diag":[0.25,0.25,0.09],
 "alphas":[0.06,0.03,0.05,0.04],"meas_var":[0.02,0.005]}
{"type":"odom","t":0.10,"d_trans":0.05,"d_rot":0.01}
{"type":"obs","t":0.20,"id":"lm1","range":2.31,"bearing":-0.42}
{"type":"truth","t":0.10,"x":0.05,"y":0.0,"theta":0.01}
```

- 长度米，角度**弧度**；`bearing` 是相对机器人航向的夹角；
- `t` 秒，**允许乱序与重复**。里程计按 `(t, 文件序)` 稳定排序；
  观测按 `(t, 路标 id, 文件序)` 排序；同一时刻严格**先里程计后观测**。
  因此乱序日志产生逐位一致的处理序列（见
  `tests/test_log_and_scenarios.py`，对完全打乱的同一份日志断言
  状态/协方差最大差异为 0）；
- `truth` 可选，只用于回放对比与测试，不参与滤波；
- 观测 `id` 必须在 `meta.landmarks` 中定义（数据关联已知）。

## HTML 回放（对应需求三）

单个 `.html`，数据与原生 JS/Canvas 逻辑全部内嵌，无外部资源、无第三方库，
双击打开即可。支持：

- 时间轴拖动、单步前进/后退、跳到开头/末尾、变速自动播放、快捷键
  （空格 / ←→ / Shift+←→ 跳事件 / Home / End）；
- 地图：当前位姿（航向三角）、95% 位置协方差椭圆、路标、估计轨迹与
  真值轨迹，发散▲/绑架▲/恢复▼ 事件直接标在地图上；
- 三联时间序列：位置误差、|航向误差|、NIS（含 95%/99%/绑架门限虚线与
  异常区间底色），曲线上可点击/拖动跳转任意时刻；
- 图层开关（估计/真值/椭圆/路标/事件）、浅深双主题（跟随系统或手动切换）、
  位姿/σ/误差/NIS 实时读数、事件列表点击跳转。

## 已知限制（滤波假设与鲁棒性）

- **EKF 一阶线性化**：强非线性（极大转角、贴路标观测）下有线性化偏差；
  单路标构型不可完全观，测试中的理想收敛用例要求两个以上路标。
- **高斯噪声假设**：里程计与观测噪声均建模为零均值高斯；多模/重尾噪声
  仅靠 R 鲁棒膨胀缓解，不能做真正的多假设跟踪。
- **数据关联已知**：观测直接带正确路标 id，不处理错误关联/路标误识别；
  关联错误会被当成野值或直接污染状态。
- **发散/绑架阈值是 χ² 启发式**：门限、连续拍数、5s 观测间隔等参数在
  `MonitorConfig` 中，可按传感器帧率与误报/漏报偏好调整；极端缓慢漂移
  （每拍都略低于门限）可能延迟或漏报。
- **恢复依赖重新看见路标**：绑架后若落点附近没有已知路标，只能报告
  绑架、无法自动重定位（无全局搜索/粒子重采样）。
- 无回环检测与全局位姿图优化，长航距累积漂移只靠路标观测局部纠正。
- 2D 平面假设成立（无 3D 姿态、无打滑以外的运动学越界）。
- 真值轨迹仅用于报告展示与测试断言，滤波器运行时不读取它。
